# Oppgave 7 — Custom calculator

## Task

Build a calculator that performs a computation of your own choice (not BMI, which was used as the course example).

The calculator must include at least:

- One number input (text box)
- One dropdown (select) where the selected value is part of the calculation
- A result that updates automatically as the user types or changes the dropdown

## Ideas

- Speed converter (km/h ↔ mph ↔ m/s)
- Cooking unit converter (cups, dl, ml)
- Tip calculator (amount + tip %)
- Power/energy calculator (watts, hours → kWh)

## Requirements

- Write a typed calculation function that takes the input value and the selected unit/option
- Update the result on both input and change events

## Stretch goals

- Show a table of converted values for a range of inputs
