# Oppgave 8 — Random artwork

## Task

Create a webpage that draws a piece of generative art on a Canvas element. The artwork should use Math.random() and update continuously using setInterval.

## Requirements

- The artwork must change over time (animated via setInterval)
- Use randomness in at least two ways (e.g. position, color, size, shape)
- The canvas size should be controlled by two variables (width / height) — changing those variables alone should be enough to resize everything

## Stretch goals

- Add buttons or sliders to control speed, density, or color palette
- Add a Clear button that wipes the canvas
