# Oppgave 4 — Numeric keypad

## Task

Place 10 buttons on the page, labelled 0 through 9. Add a disabled text field. Each time the user clicks a button, the digit on that button should be appended to the text field — allowing the user to build a number like 4327 by clicking buttons.

## Requirements

- The text field should be read-only (users type via the buttons only)
- Add a Clear button that resets the field
- Type all DOM references and event handlers

## Stretch goals

- Add a backspace button that removes the last digit
- Limit the maximum length of the number
