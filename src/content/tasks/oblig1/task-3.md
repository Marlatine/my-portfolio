# Oppgave 3 — Basic calculator

## Task

Create a form with two number inputs and four buttons: +, -, \*, /.

When the user clicks a button, calculate the result using the two numbers and display it on the page.

## Requirements

- All four operations must work
- Handle division by zero gracefully (show an error message instead of Infinity)
- Type the calculation function explicitly

## Stretch goals

- Show the full expression (e.g. 12 + 5 = 17) in the result
- Add a history list of recent calculations
