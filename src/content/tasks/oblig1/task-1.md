# Oppgave 1 — Button text toggle

## Task
Create a simple webpage with two buttons and a paragraph. Attach an event listener to each button:

- Clicking the first button changes the paragraph text to "Hei på deg"
- Clicking the second button changes it to "Ha det bra"

## Requirements
- Use TypeScript and type all DOM references explicitly
- No inline onclick attributes — use addEventListener

## Stretch goals
- Add a third button that resets the paragraph to its original text
- Disable a button after it has been clicked
