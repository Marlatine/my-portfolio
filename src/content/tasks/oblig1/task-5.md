# Oppgave 5 — Draw a house

## Task

Use the Canvas API to draw a house consisting of:

- A rectangular body
- A triangular roof
- At least one window
- A door

Before writing code, sketch the house on paper with coordinates. Remember: the x-axis points right, the y-axis points down.

## Requirements

- All drawing must happen in TypeScript using CanvasRenderingContext2D
- No external libraries

## Stretch goals

- Add a sky background with a sun or clouds
- Animate the sun moving across the sky using setInterval
