# Oppgave 9 - Beat player

## Task

Create a webpage that plays a musical "beat" using setInterval. Each tick of the interval should play one or more audio samples — optionally based on Math.random() for variation.

Find free audio samples online (drum hits, synth notes, etc.) and use the Web Audio API or HTMLAudioElement to play them.

## Requirements

- Use setInterval as the timing mechanism
- At least two different sounds
- Add a Start and Stop button

## Stretch goals

- Add Canvas visuals that react to the beat (e.g. flashing shapes)
- Let the user control tempo with a slider
- Build a simple step sequencer grid (on/off per beat per sound)
