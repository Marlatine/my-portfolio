# Oppgave 2 — True/False quiz

## Task
Create a webpage with at least three questions. Each question should be on its own line with a True and a False button next to it.

When a button is clicked, show a message saying "Riktig" or "Galt" depending on whether the chosen answer is correct.

## Requirements
- Each question must have a correct answer defined in your code
- Use data-* attributes or a typed data structure to associate buttons with their correct answer
- Display feedback per question (not a single shared message box)
- Stretch goals
- Keep a score counter and show the total at the end
- Disable both buttons after a question has been answered
